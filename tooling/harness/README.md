# Engineering Harness

Executable proof surface for agent and human engineering work.

Planned modes:
- preflight;
- fast;
- full;
- ci;
- integration.

Sensor families should cover:
- repository boundaries;
- secrets;
- dependencies;
- static analysis;
- contracts;
- migrations;
- PostgreSQL integration;
- identity;
- tenant isolation;
- policy;
- provider capability;
- evals;
- fail-closed behavior.

Model output is a candidate. Verified sensor evidence determines whether a work
package is complete.
