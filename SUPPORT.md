# Support

DROWK CRM is an early-stage open-source project.

## Questions and usage

Use GitHub Issues for reproducible bugs, feature proposals, documentation gaps, and setup problems.

Before opening an issue:

- search existing issues;
- confirm the problem occurs on a supported branch/release;
- remove credentials and sensitive data;
- provide a minimal reproduction where possible;
- include relevant environment and version information.

## Security issues

Do **not** use a public issue for vulnerabilities or suspected credential/data exposure. Follow [SECURITY.md](SECURITY.md).

## Commercial or private support

No commercial support SLA is implied by the open-source repository. Public support is best-effort and prioritized according to project impact, security, reproducibility, and maintainer capacity.
