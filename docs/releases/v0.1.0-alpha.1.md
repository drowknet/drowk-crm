# DROWK CRM v0.1.0-alpha.1

Release date: 2026-10-02

## Purpose

This is the first public alpha checkpoint for DROWK CRM as an open-source, evidence-first revenue intelligence and prospecting system.

It establishes the repository and engineering foundation for trustworthy AI-assisted CRM workflows. It is intentionally **not** a production-readiness claim.

## Included

- canonical TypeScript contracts and domain foundations;
- PostgreSQL persistence and forward-only migrations;
- tenant/membership authorization foundations;
- provider-neutral capability and research contracts;
- Gmail observation boundary with synthetic fixtures;
- deterministic work-engine behavior and regression coverage;
- relationship, commitment, and interaction continuity foundations;
- reproducible CI and PostgreSQL integration tests;
- runtime/staging-boundary verification;
- protected-main governance verification;
- CodeQL analysis;
- secret tree/history sensors;
- public-OSS privacy and internal-documentation link sensors;
- Apache-2.0 licensing and OSS contribution/governance documentation.

## Security model

The release preserves the project rule that model output is neither business truth nor execution authority.

High-impact actions remain subject to deterministic policy and, by default, human approval. Real credentials, tenant/customer data, production dumps, and private mailbox/CRM exports are not release artifacts.

See:

- [Security Policy](../../SECURITY.md)

## Reproducibility

Supported baseline:

- Node.js 22
- pnpm 10.17.1
- PostgreSQL 16 for integration verification

Install and verify:

```bash
pnpm install --frozen-lockfile
pnpm harness:ci
pnpm runtime:verify
pnpm staging:verify
```

## Known limitations

- early alpha;
- no production hosted-service guarantee;
- no live-provider credentials or tenant data included;
- Dependency Review is pending GitHub Dependency Graph enablement;
- external provider/write capabilities remain individually gated.

## Release integrity

The release candidate must be tagged only from a protected-`main` commit that has exact post-merge CI and CodeQL success.
