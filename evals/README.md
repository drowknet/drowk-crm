# Evaluations

DROWK CRM treats evaluations as product infrastructure.

Evaluation families:
- source parsing;
- relevance;
- identity/linkage;
- JEV semantic judgment;
- policy;
- research factuality;
- provider comparison;
- draft quality/voice;
- prompt injection/security;
- action trajectory/capability use.

Real historical cases must be redacted or converted into synthetic fixtures before entering this public repository.
