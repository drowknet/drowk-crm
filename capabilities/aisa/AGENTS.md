# AIsa capability scope

AIsa is a capability/provider fabric, never canonical truth.

Rules:
- request DROWK capabilities/questions, not vendor-specific business semantics;
- record selected provider/tool, cost, freshness, rights and result semantics;
- bounded empty response != universal absence;
- READ and WRITE capabilities are separate;
- direct production calls require typed adapters and budget limits;
- provider results enter Observation/Evidence before accepted CRM state.
