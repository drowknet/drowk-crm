# Code of Conduct

DROWK CRM welcomes constructive technical participation.

Contributors and maintainers are expected to communicate professionally, focus criticism on ideas and code, respect privacy and security boundaries, and avoid personal attacks or disruptive behavior.

Project maintainers may moderate or remove content and restrict participation when behavior materially harms contributors, users, or project safety.

For conduct concerns, contact the primary maintainer privately through the GitHub account associated with this repository.
